# PERBAIKAN UTS

## Aplikasi Corte Barbershop

Sebagai tindak lanjut atas hasil Ujian Tengah Semester (UTS) mata kuliah Pemrograman Mobile, Kelompok 2 melakukan pengembangan dan penyempurnaan pada aplikasi Corte Barbershop. Perbaikan ini bertujuan membuat alur penggunaan aplikasi lebih jelas bagi pelanggan serta menyiapkan tampilan pengelolaan bagi admin.

### 1. Tampilan Login dan Registrasi

Aplikasi dilengkapi halaman login dan registrasi sebagai alur awal bagi pengguna. Form registrasi menyediakan kolom nama, email, nomor HP, kata sandi, dan konfirmasi kata sandi. Validasi ditampilkan saat pengguna mengisi form, sedangkan halaman login memeriksa format email dan kata sandi sebelum pengguna melanjutkan ke aplikasi.

Pada tahap prototipe ini, akun masih digunakan untuk simulasi lokal dan belum disimpan ke database atau layanan autentikasi.

### 2. Dashboard Admin

Tampilan dashboard admin di kembangkan oleh teman teman `Kelompok 2`. Halaman ini disiapkan sebagai area admin untuk melihat informasi dan mengelola kebutuhan operasional aplikasi Corte Barbershop. Perubahan pada branch tersebut perlu ditinjau melalui Pull Request dan digabungkan ke branch `main` agar menjadi bagian dari versi utama proyek.

### 3. Dashboard User

Halaman Home digunakan sebagai dashboard pengguna. Dari halaman ini, pengguna dapat melihat informasi barbershop dan layanan, memulai booking, membuka katalog produk, serta menuju halaman pesanan dan profil. Susunan tersebut membantu pengguna menemukan fitur utama dari satu halaman.

### Penutup

Perbaikan ini merupakan langkah langkah menuju penyempurnaan aplikasi Corte Barbershop dari sisi alur akses dan tampilan sesuai kebutuhan pengguna dan admin. Pengembangan selanjutnya dapat mencakup penyimpanan data permanen, autentikasi yang terhubung ke backend, serta penyelesaian dan penggabungan dashboard admin ke branch utama.
